## Requirements

- NZBGet v23+ and Python 3.8+

# ExtendedUnpacker
[Post-processing](https://nzbget.com/documentation/post-processing-scripts/) script for [NZBGet](https://nzbget.com).

This script extracts nested zip and rar archives from downloaded files.

## Installation

- Download the newest version from [releases page](https://github.com/nzbgetcom/Extension-ExtendedUnpacker/releases).
- Unpack into pp-scripts directory. Your pp-scripts directory now should have folder "ExtendedUnpacker" with "main.py" and "manifest.json";
- Open settings tab in NZBGet web-interface and define settings for ExtendedUnpacker;
- Save changes and restart NZBGet.
